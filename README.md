# Personal Portfolio Website

A simple and responsive personal portfolio website developed as part of the **Full Stack Development** assignment.

* Responsive design using Bootstrap

* Home, About, Education, Skills, Projects, and Contact sections

* Dark/Light theme toggle

* Contact form with basic JavaScript validation

## Technologies Used

* HTML5

* CSS3

* Bootstrap 5

* JavaScript (ES6)
